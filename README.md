# Healthchecker API

A minimal REST API built with **Node.js**, **Express**, and **TypeScript**.  
It exposes a single `/health` endpoint and returns clean JSON errors for unknown routes.

---

## What the API does

| Endpoint         | Method | Response                                         |
|------------------|--------|--------------------------------------------------|
| `/health`        | GET    | `200 { "status": "ok", "message": "..." }`       |
| _anything else_  | ANY    | `404 { "status": "error", "message": "..." }`    |

A global error handler ensures the server never crashes on unexpected errors —
it always returns a `500` JSON response instead.

---

## Prerequisites

- [Node.js](https://nodejs.org/) v18 or higher
- npm (comes with Node.js)

---

## Install dependencies

```bash
npm install
```

---

## Run locally (development)

```bash
npm run dev
```

The server starts on **http://localhost:3000** by default.  
You can change the port by setting the `PORT` environment variable:

```bash
PORT=4000 npm run dev
```

---

## Build for production

Compile TypeScript → JavaScript inside the `dist/` folder:

```bash
npm run build
```

Then start the compiled server:

```bash
npm start
```

---

## Deploy on Render

1. Push this project to a **GitHub repository**.
2. Go to [render.com](https://render.com) and create a **New → Web Service**.
3. Connect your GitHub repo.
4. Fill in the settings:

   | Setting        | Value           |
   |----------------|-----------------|
   | Environment    | Node            |
   | Build Command  | `npm install && npm run build` |
   | Start Command  | `npm start`     |

5. Click **Create Web Service** — Render will build and deploy automatically.  
   Render injects `PORT` automatically; the app reads it via `process.env.PORT`.

## Test the endpoints

### In a browser

- **Health check** → open `http://localhost:3000/health`  
  Expected response:
  ```json
  { "status": "ok", "message": "API is running successfully" }
  ```

- **Unknown route** → open `http://localhost:3000/anything-else`  
  Expected response:
  ```json
  { "status": "error", "message": "Route not found" }
  ```

### With curl

```bash
# Health check
curl http://localhost:3000/health

# Unknown route
curl http://localhost:3000/unknown
```
